# Deutsch-Heft

Личная тетрадь по немецкому: словарь с артиклями и тренировкой, спряжения, свои правила грамматики. Работает без Claude и без интернета. Интернет нужен только для перевода новых слов (Викисловарь и MyMemory, оба бесплатные и без ключей).

Внутри уже лежат 327 слов, 37 глаголов и 10 правил. Они загружаются при первом запуске.

## Как поставить на телефон

Приложению нужен адрес в интернете (https), иначе телефон не даст его установить. Проще всего сделать это через GitHub Pages, это бесплатно.

1. Создай на GitHub новый публичный репозиторий, например `heft`.
2. Загрузи в него все файлы из этой папки: *Add file → Upload files*.
3. Открой *Settings → Pages*, выбери *Deploy from a branch → main → / (root)* и нажми *Save*.
4. Через минуту приложение будет по адресу `https://<твой-логин>.github.io/heft/`.
5. **iPhone:** открой адрес в Safari → «Поделиться» → «На экран Домой».
   **Android:** открой в Chrome → меню → «Установить приложение».

Дальше Heft открывается с иконки на весь экран и работает офлайн.

## Где хранятся слова

Только на телефоне, в памяти приложения. Аккаунтов и серверов нет. Поэтому:

- **резервная копия:** «Данные» → «Сохранить файл .json». На iPhone файл можно сохранить в «Файлы» или в iCloud Drive;
- **новый телефон:** поставь приложение там и в «Данных» загрузи этот файл;
- если удалить иконку с экрана «Домой», данные удалятся вместе с ней. Сначала сделай копию.

## Обновления

Если поменяешь файлы в репозитории, приложение подхватит новую версию после второго запуска. Чтобы обновление пришло наверняка, увеличь номер в `sw.js` (`heft-v1` → `heft-v2`). Твои слова при обновлении не трогаются.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | само приложение |
| `seed.js` | стартовые слова, глаголы и правила (нужны только при первом запуске) |
| `sw.js` | офлайн-режим |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | иконка и установка на экран «Домой» |
